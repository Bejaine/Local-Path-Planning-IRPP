## Local Path Planning & Navigation using TurtleBot3 in Gazebo & RViz
Code files for the implementation of local path planning & navigation in unknown environments using the TurtleBot3 in Gazebo & RViz. \
The Dynamic Window Based Controller with Vector Field Histogram (DWB+VFH) and Model Predictive Path Integral (MPPI) path planning algorithms were evaluated in self created static enviroments, dynamic environments and an urban cityscape junction. \
Algorithm theory was presented and performance analysis of the simulations were produced. \
